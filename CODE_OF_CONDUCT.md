# Code of Conduct

This project was built through patient, candid collaboration between people who assumed good faith in each other. Keep it that way.

**Expected:**

- Be respectful and professional in issues, pull requests, and reviews.
- Criticize code and ideas, never people. Blunt technical honesty is welcome here; contempt is not.
- Assume the person reporting a bug is describing something real, even when it sounds impossible. This project's history is a string of "impossible" reports that turned out to be precisely accurate.
- Respect other people's privacy. Never post someone else's messages, phone numbers, addresses, or identifying logs.

**Not tolerated:**

- Harassment, discrimination, or personal attacks of any kind.
- Publishing private information of others.
- Sustained disruption or bad-faith participation.

**Enforcement:** maintainers may edit, remove, or lock contributions that violate this document, and may block repeat offenders. To report a problem privately, contact the maintainers through GitHub rather than in a public thread.
